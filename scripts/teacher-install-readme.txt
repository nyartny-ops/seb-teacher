SAFE EXAM BROWSER С ПАНЕЛЬЮ ПРЕПОДАВАТЕЛЯ — УСТАНОВКА
====================================================

1. Перетащите «Safe Exam Browser» в папку «Программы» (Applications).
   Если на Mac уже стоит официальный SEB, он будет заменён этой версией.

2. Первый запуск. Приложение подписано без сертификата Apple, поэтому
   macOS сначала его не откроет. Сделайте один раз на каждом Mac:

   • Откройте «Safe Exam Browser» двойным щелчком — появится
     предупреждение, нажмите «Готово»/«Отмена».
   • Системные настройки → Конфиденциальность и безопасность →
     внизу «Safe Exam Browser заблокирован…» → «Всё равно открыть»
     → введите пароль администратора Mac.

   Либо в Терминале (быстрее, если Mac много):
       xattr -dr com.apple.quarantine "/Applications/Safe Exam Browser.app"

3. SEB попросит разрешения (Универсальный доступ, Запись экрана и др.) —
   выдайте их в Системных настройках, иначе часть ограничений не работает.

ПАНЕЛЬ ПРЕПОДАВАТЕЛЯ
--------------------
При запуске SEB показывает окно:
  • «Начать контрольную» — запуск с сохранёнными настройками;
  • «Настройки преподавателя…» — пароль 32123212;
  • «Выйти».

В настройках:
  • уровень контроля: Мягкий / Стандартный / Строгий (потом любой пункт
    можно поменять вручную — уровень станет «Свой»);
  • переключатели ограничений и дополнений;
  • пароль выхода и разблокировки (по умолчанию — пароль преподавателя);
  • адрес контрольной (например, ссылка на тест в Moodle).

Настройки сохраняются для текущей учётной записи macOS — задавайте их
под той учётной записью, в которой будут работать студенты.

Если во время контрольной включено «Запретить смену цветов экрана», то
при включении инверсии, оттенков серого, цветофильтров, контраста или
тёмной темы экран SEB блокируется до ввода пароля разблокировки.
