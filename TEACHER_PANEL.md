# SEB с панелью преподавателя

Перед стартом контрольной SEB показывает окно преподавателя. Пароль к настройкам: **32123212**.

- **Начать контрольную** — запуск с сохранёнными настройками. Можно включить требование пароля и для этой кнопки.
- **Настройки преподавателя…** — уровень контроля (Мягкий / Стандартный / Строгий / Свой) и переключатели:
  - *Экран и окна:* полный экран, запрет сворачивания/скрытия (⌘M, ⌘H), один монитор, запрет дублирования экрана, новые окна по ссылкам, нижняя панель SEB.
  - *Ограничения системы:* другие программы, проверка ⌘ при старте, скриншоты и запись экрана, демонстрация экрана, виртуальные машины, отдельный буфер обмена, программы-помощники, приостановка SEB, **смена цветов экрана**, светлое оформление.
  - *Дополнения:* орфография, словарь, диктовка, Siri, печать, поиск, масштаб, файлы, правая кнопка, Назад/Вперёд, перезагрузка, часы, консоль разработчика.
  - *Выход:* разрешить выход, пароль выхода и разблокировки, встроенные настройки SEB по Option, адрес контрольной.
- **Выйти**.

## Где что в коде

| Файл | Что делает |
|---|---|
| `Classes/TeacherPanel/SEBTeacherSettings.{h,m}` | Список переключателей, уровни контроля, хранение (с HMAC), применение к ключам SEB, перехват ⌘M/⌘H, контроль цветов |
| `Classes/TeacherPanel/SEBTeacherPanelController.{h,m}` | Окно панели (AppKit, без xib) |
| `Classes/SEBController.m` | Показ панели в `-conditionallyInitSEBWithCallback:selector:`, применение настроек при каждом (пере)запуске сессии, блокировка при смене цветов, отключение обхода через Option |
| `SafeExamBrowser.xcodeproj/project.pbxproj` | Новые файлы в таргете «Safe Exam Browser»; убрана ссылка на закрытую `libSEBSupport.a` |
| `scripts/build-teacher-dmg.sh` | Сборка `build/SEB-Teacher.dmg` на Mac с Xcode |
| `.github/workflows/build-macos.yml` | То же самое на облачном Mac GitHub Actions |

Новый переключатель добавляется в `+[SEBTeacherSettings allOptions]` (название, подсказка, значения для трёх уровней). Связь с ключом SEB задаётся в `-applyToSEBPreferences`.

Смена пароля: в `SEBTeacherSettings.m` замените `SEBTeacherPasswordHash` на результат `printf %s 'новый' | shasum -a 256`.

## Сборка

**На своём Mac:** установите Xcode, затем выполните `bash scripts/build-teacher-dmg.sh`.

**Без Mac:** загрузите проект в репозиторий GitHub, откройте Actions → «Build SEB Teacher (macOS)» → Run workflow и скачайте `SEB-Teacher-dmg` из Artifacts.

## Ограничения сборки

- Сборка подписана ad-hoc, без сертификата Apple. При первом запуске нужно подтверждение в «Конфиденциальность и безопасность» (см. `scripts/teacher-install-readme.txt`). С аккаунтом Apple Developer подпись и нотаризацию включают секреты в workflow.
- Entitlement Automatic Assessment Configuration Apple выдаёт только по запросу, поэтому всегда используется классический киоск-режим SEB (`lockdownModePolicy = EnforceClassic`).
- Настройки панели накладываются поверх настроек из `.seb` файла. Из-за этого Config Key / Browser Exam Key может отличаться от ключа исходного `.seb`. Если в Moodle включена проверка ключей SEB, сверьте ключ на тестовом запуске.
